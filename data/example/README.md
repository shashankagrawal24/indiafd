# Example output - synthetic, not real rates

Generated by `python -m fdrates run --offline-dir tests/fixtures --out data/example`.

The eight banks with `status=ok` were parsed from the **hand-written fixtures** in
`tests/fixtures/`, so the numbers are invented. Every other bank shows
`status=blocked` with the note "offline mode: no local snapshot" - that is what
offline mode does, not a statement about the bank's website.

This folder exists to show the CSV shape and the report format before the first
real run. Real output lands in `data/latest/` and `data/history/<date>/`.
